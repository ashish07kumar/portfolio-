# Ashish Kumar — React Portfolio

A responsive portfolio recreation built with React, JavaScript, Vite, and Tailwind CSS.

## Requirements
- Node.js 18+ recommended
- npm

## Run locally
```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build
```bash
npm run build
npm run preview
```

## Personalize it
- Edit profile text, skills, projects, education, and links in `src/data.js`.
- Replace `public/profile-placeholder.svg` with your own photo if desired.
- Update project links in `src/data.js`.
- The contact section currently opens the visitor's email app using a `mailto:` link. It is not a backend-powered form.

## Honest note
This is a standalone recreation, not recovered original source code from the live Netlify deployment. Original private source files, exact animations, and original assets cannot be guaranteed from a public URL alone.
